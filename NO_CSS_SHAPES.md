# No CSS Shapes Rule

For the Shelf of Fame botanical room, scenery must come from real image assets.

CSS may be used for layout, responsive sizing, positioning, cropping, opacity, color correction, shadows, and lighting falloff.

CSS must not fabricate room geometry, walls, floors, furniture, windows, trim, decor, or perspective using pseudo-elements, polygons, clip-paths, shape-only elements, or similar synthetic drawing techniques.

When the scene needs a new physical object or architectural feature, add or edit an image asset instead of drawing it in CSS.
